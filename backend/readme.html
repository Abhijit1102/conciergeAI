02

Setup

1
Configure environment

Copy .env.example to .env and fill in the three required secrets.

MONGODB_URL=mongodb+srv://user:pass@cluster.mongodb.net/db
GEMINI_API_KEY=AIza••••••••••••••••••••••••••••••
JWT_SECRET=your-32-char-minimum-secret-here # min 32 chars
2
Install dependencies
bash
$ pip install -r requirements.txt
3
Run the dev server
bash
$ uvicorn app.main:app --reload   # API → http://localhost:8000 # Docs → http://localhost:8000/docs
03

Docker

bash
# Build image $ docker build -t ai-event-concierge-backend .   # Run container $ docker run -p 8000:8000 --env-file .env ai-event-concierge-backend
